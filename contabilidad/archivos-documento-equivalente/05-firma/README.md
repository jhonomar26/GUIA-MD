# Feature: firmar documentos del documento equivalente

| Campo | Valor |
|---|---|
| Módulo | contabilidad |
| Área | archivos-documento-equivalente |
| Menú | Pantalla de archivos del documento equivalente (`~/DocumentoContableArchivo/?iddocumentoequivalente=<id>`) |
| Estado | hecha y cerrada (2026-10-22): el usuario probó la firma a mano y funcionó; sin captura registrada |

Un PDF cargado de un tipo con firma electrónica se envía a firmar al tercero del documento equivalente. La firma en sí no cambia.

Depende de: [03-subir-archivo](../03-subir-archivo/).
