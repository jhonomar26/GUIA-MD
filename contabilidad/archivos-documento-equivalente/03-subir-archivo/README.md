# Feature: subir archivos al documento equivalente

| Campo | Valor |
|---|---|
| Módulo | contabilidad |
| Área | archivos-documento-equivalente |
| Menú | Se abre desde **Documento Equivalente** (`~/DocumentoEquivalente/EdicionV2`), botón **"Adjuntar"**, y desde la pantalla de combos |
| Estado | hecha; evidencia parcial (E1, E6b) |

Sobre un pendiente del documento equivalente se sube su archivo. La pantalla muestra pendientes, vencidos y cargados (locales y remotos) solo de ese documento.

Depende de: [02-solicitar-documentos](../02-solicitar-documentos/) (sin pendientes no hay a qué subir).
