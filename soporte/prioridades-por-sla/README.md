# prioridades-por-sla

El portal solo ofrece las prioridades parametrizadas en el SLA del motivo elegido. Si el motivo no tiene SLA, no se crea el ticket y se pide contactar a soporte. Se elimina el tiempo automático de 72h.

| Doc | Qué es |
|---|---|
| [REQUERIMIENTO.md](./REQUERIMIENTO.md) | Pedido, criterios Dado/Cuando/Entonces y fuera de alcance |
| [ANALISIS.md](./ANALISIS.md) | Qué existe hoy, regla nueva, hallazgos y verificación |
| [PLAN.md](./PLAN.md) | Plan técnico: 5 tareas (datos, negocio, endpoint, pantalla, motivos sin SLA antes de desplegar) |
