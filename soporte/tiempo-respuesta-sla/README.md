# tiempo-respuesta-sla

El SLA agrega un tiempo de respuesta que se suma al de resolución para calcular la fecha límite del ticket (ej. 2 h + 4 h = 6 h hábiles). No se registra cuándo contestó soporte.

| [PLAN.md](./PLAN.md) | Plan técnico: 2 tareas (columna + suma en la fecha límite, pantalla de parametrización) |
